# SkillConnect

SkillConnect is a web application that connects people who want to learn new skills with people who can teach those skills. Users create profiles, list skills they can teach or want to learn, and connect with others based on shared interests.

## Problem

Many people want to learn new skills but struggle to find affordable learning opportunities or people willing to share their knowledge. SkillConnect solves this by matching learners with teachers directly, based on real skill listings rather than generic course catalogs.

## Core Features

- User registration, login, and profile management
- Create and manage skill listings
- Search and browse skills offered by other users
- Send and manage learning or connection requests
- Edit and delete personal skill listings

## Getting Started

Clone the repo and install dependencies:

\`\`\`bash
git clone https://github.com/AGCondori95/skillconnect.git
cd skillconnect
npm install
\`\`\`

Run the development server:

\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Branching & Contribution Workflow

- `main` is protected — no direct pushes.
- All work happens on feature branches named `feature/<short-description>` (e.g. `feature/user-auth`).
- Open a pull request into `main`; it requires at least one approving review before merge.
